✦ Key Features

Everything you need,
nothing you don't.

Packed with power-user features while staying lightweight. Hover each card to preview the interface.

🪟

Dynamic Window Modes

Toggle between Standard Desktop Window (resizable with Dock icon) and Menu Bar Panel (frameless status bar popup) directly from Settings.

🔔

True Native Notifications

Direct integration with macOS Notification Center — respects Focus Modes, Do Not Disturb, Lock Screen, and native alert sounds with per-service icons.

💤

Smart RAM Auto-Sleep

Automatically unloads memory for background tabs after idle duration. The service reconnects instantly the moment you switch back.

🎯

Filters & Scheduled DND

Regex-based Priority / Allow / Deny rules per service, plus a full quiet-hours schedule editor with day & time windows.

🌐

8+ Apps + Custom URLs

Works out-of-the-box with Messenger, Zalo, Gmail, Outlook, Slack, Discord, Telegram, WhatsApp — plus any custom web URL.

🚦

Live Connection Status

Visual status dots turn amber or red if a service loses network activity or needs sign-in — dead connections never look like "no messages".

⌨️

Hotkeys & CLI Companion

Record any global hotkey (e.g. ⌘⇧Space) to toggle the app anywhere. Full notihub CLI for scripting and automation.

🛠️

Automatic Crash Recovery

Crashed or hung renderers reload themselves automatically with exponential backoff — no sitting on blank tabs.

📦 Installation

Up and running
in seconds.

Three ways to install. Pick what works best for you. Requires macOS 12 Monterey or later.

Method 1

Via Homebrew

The fastest way. Add the tap and install with Homebrew Cask.

brew tap Thuong180702/notihub https://github.com/Thuong180702/notihub
brew install --cask notihub

Or install directly via URL:

brew install --cask https://raw.githubusercontent.com/Thuong180702/notihub/main/Casks/notihub.rb
Method 2

Direct Download

Download the latest release zip, unzip, and drag to Applications.

↓ GitHub Releases
Method 3

Build from Source

Clone the repo and build locally. Requires Node.js ≥ 18.

git clone https://github.com/Thuong180702/notihub.git
cd notihub
npm install && npm run build
